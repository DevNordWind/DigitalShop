# Общее

---

### 👥 Иерархия ролей и уровни доступа

Иерархия ролей в боте представлена тремя ролями: `Супер-администратор`, `Администратор`, `Пользователь`.

Каждая роль наследует права нижестоящей роли(например, `Супер-администратор` может пользоваться всеми правами `Администратора`) и имеет собственные права.

- **Супер-администратор:** Главный управляющий ботом. В отличие от обычного администратора, он имеет право назначать, изменять или забирать права у других пользователей. Супер-администратором может стать только тот пользователь, чей Telegram ID указан в файл `config.yaml`(не считая прямого вмешательства в БД).
- **Администратор:** Управляет контентом, товарами и настройками магазина, но не может назначать других администраторов.
- **Пользователь:** Обычный клиент бота.

### 🇷🇺🇬🇧🇺🇦 Мультиязычность

Бот поддерживает полноценную работу на трех языках: **Украинский**, **Русский** и **Английский**. Мультиязычность реализована на двух уровнях:

1. **Интерфейс бота (Системная мультиязычность):** Все стандартные сообщения, кнопки и меню переведены заранее и вшиты в систему (используется формат Fluent, в папке `texts/`). Пользователь видит интерфейс на выбранном им языке.
2. **Контент магазина (Динамическая мультиязычность):** Названия и описания `Категорий` и `Позиций` (товаров), которые администраторы добавляют в процессе работы.
	 - _Особенность заполнения:_ При создании нового товара или категории обязательным для заполнения является только **язык по умолчанию**. На основе языка по умолчанию осуществляются переводы на остальные языки


### 💳 Мультивалютность и финансы

Финансовая система бота разработана для работы с несколькими рынками и поддерживает 4 валюты: **USD**, **RUB**, **UAH**, **KZT**.

- **Актуальные курсы** предоставляет Crypto Pay API (@cryptobot), курсы обновляются каждые 6 часов.

- **Точность расчетов:** Все балансы и операции хранятся и обрабатываются с использованием точного банковского округления.

- **Ценообразование:** Каждая `Позиция` обязана иметь цены во всех поддерживаемых валютах. Валюта по умолчанию является валютой, от которой производятся конвертация во все остальные валюты при заполнении цен.

- **Кошельки пользователей:** У каждого покупателя есть 4 независимых баланса (под каждую валюту соответственно). Валюта, которую пользователь выбрал в настройках, используется как для отображения цен в каталоге, так и для списания средств при покупке.

# 🛠 Админ-панель

---

### 🗃 Категории

- **Статусы:** у категории бывает два статуса: `Доступная` и `Заархивированная`. `Доступные` категории открыты к редактированию, но не могут быть удалены. `Заархивированные` категории закрыты к редактированию, и могут быть удалены. Кроме того, `Заархивированные` категории не видны пользователям.
- **Медиа:** каждая категория поддерживает только одно медиа-вложение(GIF, фото, видео)
- **Описание** категории является необязательным

###### ⚙️ Настройки категорий

- **🇷🇺🇬🇧🇺🇦 Язык по умолчанию** становится **обязательным** при создании новых категорий. **Авто-перевод** на другие языки осуществляется на его основе

- 📦 **Категории без товаров:** если выбрано `🚫 Скрыть`, то категория не будет показана пользователю, если во всех `Позициях` `Категории` отсутствуют товары

### 📁 Позиции

- **Статусы:** у позиции бывает два статуса: `Доступная` и `Заархивированная`. `Доступные` позиции открыты к редактированию, но не могут быть удалены. `Заархивированные` позиции закрыты к редактированию, и могут быть удалены. Кроме того, `Заархивированные` позиции не видны пользователям.
- **Медиа:** каждая позиция поддерживает до 10 медиа-вложение(GIF, фото, видео)
- **Описание** позиции является необязательным
- **Цены** позиции должны быть явно указаны во всех четырёх валютах

###### ⚙️ Настройки позиции

- **🇷🇺🇬🇧🇺🇦 Язык по умолчанию** становится **обязательным** при создании новых позиций. **Авто-перевод** на другие языки осуществляется на его основе

- 📦 **Позиции без товаров:** если выбрано `🚫 Скрыть`, то позиция не будет показана пользователю, если у неё нет хотя бы одного товара

- **🪙 Валюта по умолчанию** становится базовой валютой при конвертации в остальные валюты

### 🎫 Купоны

- **Статусы:** у купона есть 4 статуса: `Активный`, `Отозванный`, `Истёкший`, `Ожидающий`. Активны
	1. `Активным` является купон, который может быть использован пользователем в данное время
	2. `Отозванным` является купон, который администрация приняла решение отозвать
	3. `Истёкшим` является купон, срок действия которого истёк
	4. `Ожидающим` является тот купон, срок действия которого ещё не начался
- **Код купона** обязан быть уникальным
- **Время действия** делится на начало действия купона, и окончание действия купона.
	1. Если действие начало купона не указано - купон начинает действовать с момента создания
	2. Если окончание действия не указано - купон действуют бесконечно
- **Тип купона:** купон может быть двух типов: `Фиксированная сумма`, `Процент от суммы заказа`.
	1. Купон с типом `Процент от суммы заказа` универсален для любой валюты
	2. Купон с типом `Фиксированная сумма` действует только для указанных валют
	3. Если купон полностью покрывает стоимость заказа - пользователь имеет право оформить его без оплаты

### 🔎 Поиск пользователей

- **Поиск** пользователя возможен в меню `👥 Пользователи` - `🔎 Поиск`, осуществляется по Telegram ID или внутреннему идентификатору вида `019f3e33-19df-77de-8988-cb332e54e35d`
- **Найденному пользователю** может быть присвоена новая роль(только для `Супер-администраторов`), выдан баланс, а также есть возможность посмотреть все заказы пользователя

### 📢 Рассылка

- **Рассылки** можно проводить на всех трёх языках одновременно. Сообщение рассылки получат только те пользователи, чей язык есть в текстах рассылки
- **Медиа:** поддерживается одно медиа-вложение
- **Кнопки:** для рассылки есть возможность отключить кнопку закрытия, а также добавить URL-кнопки

### ⚙️ Главные настройки

- **Технические работы** включены по умолчанию, обычные пользователи не смогут продолжать пользоваться ботом, и получат сообщение о проведении технических работ
- **Тех.поддержка** - указанные контакты будут отображаться в меню `ℹ️ Информация`

### 💳 Платёжные системы

- Каждую платёжную систему можно выключить
- Для каждой платёжной системы можно задать комиссию
